# Запуск 24/7 бесплатно: GitHub Actions

Идея: GitHub раз в 5–15 минут запускает наш скрипт на своём сервере, скрипт проверяет
обстановку и отправляет push на телефон. Компьютер и сервер не нужны.

**Важно понимать заранее:**

- GitHub не гарантирует точное время: проверка идёт «примерно каждые 5–15 минут». Для
  коротких событий можно опоздать.
- Через 60 дней без активности в репозитории GitHub отключает расписание и присылает письмо —
  включается обратно одной кнопкой.
- Репозиторий должен быть **публичным**: у приватных бесплатно только 2000 минут Actions
  в месяц, а нам нужно ~300 запусков в день.
- Если сайт блокирует зарубежные адреса (серверы GitHub в США/Европе), в логе будет ошибка —
  тогда нужен VPS или домашнее устройство (см. `deploy/README-deploy.md`).

## Шаг 1. Аккаунт GitHub

Если нет — зарегистрируйтесь на <https://github.com> (бесплатно, нужна почта).

## Шаг 2. Загрузить папку в репозиторий

Папка `detector-aero` уже подготовлена как git-репозиторий, осталось его опубликовать.

1. Установите **GitHub Desktop**: <https://desktop.github.com> и войдите в свой аккаунт.
2. Меню **File → Add local repository…**
3. Укажите папку `detector-aero` (там, где лежит `watch.mjs`). Нажмите **Add repository**.
4. Нажмите кнопку **Publish repository** (справа сверху).
   - Name: `detector-aero`
   - **Снимите галочку «Keep this code private»** — репозиторий должен быть публичным.
   - Publish.

## Шаг 3. Положить топик ntfy в секреты

1. Откройте репозиторий на github.com → **Settings** → **Secrets and variables** → **Actions**.
2. **New repository secret**:
   - Name: `NTFY_TOPIC`
   - Secret: `dtr-aero-bt-8c4f2e91a7`
3. **Add secret**.

Топик в открытом репозитории держать нельзя — иначе кто угодно сможет слать вам сообщения.
Поэтому он лежит в секрете и передаётся скрипту через переменную окружения.

## Шаг 4. Первый запуск

1. Вкладка **Actions** → слева «Детектор АЭРО — проверка неба».
2. Справа **Run workflow** → **Run workflow**.
3. Через минуту откройте запуск и посмотрите лог: должно быть «проверка завершена».
4. Если сейчас в районе есть опасность — на iPhone придёт push. Проверить канал отдельно:

```powershell
cd "C:\Users\саша\Documents\deepseek-harness\default-workspace\detector-aero"
$env:NTFY_TOPIC="dtr-aero-bt-8c4f2e91a7"; node watch.mjs --test
```

## Чтобы не было двойных уведомлений

Пока на компьютере работает локальный наблюдатель (задача `DetectorAeroWatch`), он тоже
отправляет push — и об одном событии придёт два сообщения. Когда убедитесь, что GitHub
присылает уведомления, локальный лучше остановить:

```powershell
cd "C:\Users\саша\Documents\deepseek-harness\default-workspace\detector-aero"
powershell -ExecutionPolicy Bypass -File .\install-autostart.ps1 -Uninstall
```

Всплывающие уведомления Windows при этом пропадут — останутся push на телефон.

## Как это устроено
```
GitHub Actions (cron */5)
   └─ node watch.mjs --check        один опрос, без цикла
        ├─ восстанавливает state.json из кэша (что уже объявлено)
        ├─ спрашивает detector-aero.ru
        ├─ новые угрозы → push в ntfy → iPhone
        └─ сохраняет state.json обратно в кэш
```

Состояние между запусками хранится в кэше Actions: ключ `state-<номер запуска>`,
восстановление по префиксу `state-`. Так повторных уведомлений об одном событии не будет.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| В логе `Не задан секрет NTFY_TOPIC` | Шаг 3 не выполнен |
| `fetch failed` / таймаут | Сайт недоступен с зарубежных адресов — нужен VPS |
| Push не приходит | Не подписаны на топик в приложении ntfy |
| Расписание перестало запускаться | 60 дней без активности — включите заново в Actions |
